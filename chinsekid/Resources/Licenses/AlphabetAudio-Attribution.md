# Alphabet audio attribution

These offline recordings are provided as separate audio assets. Original Ogg Vorbis/Opus files were transcoded to MP3; no speech content was edited. The letter-name recordings are a mixed-source set, so the voice can change between letters. The example sentences are from one A–Z set by Simon Kågedal Reimer.
