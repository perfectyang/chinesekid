# 汉字探险队

## App 简介

汉字探险队是一款面向小学生的 iPad 汉字学习 App。孩子可以从身边的照片或手动输入中收集生字，在汉字图鉴里查看和复习，并通过“听音找字”小游戏巩固记忆。界面采用明亮、活泼的绘本风格，学习记录按小朋友档案分别保存。

## 功能介绍

### 1. 小朋友档案

- 可以创建多个小朋友档案，并在档案之间切换。
- 可以修改昵称，也可以用相机拍照或从相册选择头像。
- 每个档案分别保存自己的汉字图鉴、学习进度、错题和练习题组。
- 删除档案前会再次确认；删除后，该档案关联的学习资料也会一并删除。

### 2. 拍照识字

- 可以直接拍摄照片，也可以从相册选择照片。
- App 使用 iOS 自带的文字识别能力查找图片中的汉字。
- 识别完成后，孩子可以逐字选择要加入图鉴的汉字，也可以一次选择多个字。
- 照片只用于识别，不会作为学习资料保存在 App 中。
- 已经收录过的字会标记出来，避免重复添加。

### 3. 手动和批量录入

- 可以输入或粘贴一段文字，App 会从中提取汉字供孩子挑选。
- 可以一次选择多个新字加入图鉴。
- 已经收录的字会自动跳过。

### 4. 汉字图鉴

- 集中查看当前档案收集到的汉字、拼音和学习状态。
- 点选汉字可以打开学习卡片；卡片可上下滑动浏览其他汉字。
- 学习卡片提供汉字读音、字义（有收录时）和笔顺动画（有笔顺资料时）。
- 对已收录多音字，卡片会显示不同拼音的读音标签；切换标签可查看对应例词并播放读音。
- 可以标记汉字为“已认识”或“再练练”，帮助安排后续复习。

### 5. 汉字探险与进度

- 从图鉴中随机抽取一组汉字进行卡片复习。
- 首页显示已认识的字数和待复习字数。
- 复习结果会更新汉字状态和下次复习时间，并记录在当前档案中。

### 6. 听音找字

- 可以练习全部生字、最近收集的汉字、听音错题，或自己创建的练习题组。
- 每组题目从所选汉字中出题，每题提供四个汉字选项；孩子听读音后选择对应汉字。
- 作答后会即时显示对错，再自动进入下一题；选项答案位置会随机安排。
- 一轮结束后显示成绩；答错的汉字可以单独再练。
- 自选题组支持命名、选择汉字、编辑和删除。编辑会更新原题组，不会额外创建重复组。

## 数据与隐私

- 汉字、档案、练习题组和学习记录保存在 iPad 本地 SQLite 数据库中。
- 图片识别完成后即可丢弃，照片不会保存到汉字图鉴。
- 头像图片保存在本地设备中，并关联到相应档案。

## 主要页面

| 页面 | 用途 |
| --- | --- |
| 首页 | 查看学习进度，进入汉字探险、拍照识字、手动录入和听音找字 |
| 汉字图鉴 | 浏览当前档案收集的汉字并打开学习卡片 |
| 发现新汉字 | 拍照或从相册识别汉字，选择后导入图鉴 |
| 手动录入 | 输入或粘贴文字，批量挑选汉字导入 |
| 选择练习题组 | 开始快捷练习或管理自选题组 |
| 我的档案 | 切换、添加、改名或删除档案，以及更换头像 |
