# Reference fish collection

Six volumetric Unity models inspired by the three user-provided images. The hidden surfaces, depth and animation are modeled interpretations, not recovered geometry from the screenshots. No external image-to-3D service was used.

- Prefabs: `Assets/Resources/OpenSea/Fish/<name>.prefab`.
- Persistent meshes, materials and textures: `Assets/Art/ReferenceFishCollection/`.
- Each PNG named after a prefab is rendered from the actual mesh: side, three-quarter front, top.
- Regenerate assets and previews: Unity menu **Chinsekid → Fish Game → Create Reference Fish Collection**, or execute `Chinsekid.FishGame.Editor.ReferenceFishCollectionSetup.PrepareAndRender`.
- Forward axis is +Z. Visual bounds use the same limits as imported game fish: length ≤2.65, width/height ≤1.65, without modifying gameplay actor scale.
- All models use the existing tail/paired-fin animation component and normal/boost animation callback. Static details are combined by material; animated joints remain separate.
- All six are registered in the random species pool. The initial school contains one of each (fang fish level 3, shark level 4); subsequent ordinary spawning uses level-appropriate pools. Existing fish are retained. The native skin selector now includes these six models, GoldenReference and the previously unlisted Tang, using actual transparent model snapshots. Existing unlocked progress is preserved and duplicate legacy skin IDs migrate to canonical entries.

Source images are retained here as modeling references; this note does not assert ownership or an open-source license for the supplied images.

Native thumbnails are generated by `Chinsekid.FishGame.Editor.FishSkinThumbnailSetup.RenderAll` into `chinsekid/Resources/FishModelPreviews/`. Swift `unityModelName` and Unity `ModelForSkin` identify the same assets. There are 21 distinct selectable appearances, including the existing procedural shrimp and octopus.

## Iridescent great white shark

`IridescentShark` is a separate volumetric interpretation of the user-supplied side, front and top references (`source-iridescent-shark-*.png`). It has a blue-grey back with painted rainbow sheen, pale belly, amber eyes, three gill slits, a recessed tooth-lined mouth, swept pectoral fins and crescent tail. It uses the existing tail/paired-fin animation component. Geometry and the painted sheen are authored locally, not reconstructed by an image-to-3D service. The finish is stylized rather than a photorealistic replica.

It is registered in the level-3-and-up random model pool and as one level-6 roaming predator in each initial Unity school. It uses the same chase/rest behavior as other predators. The native selector calls it 幻彩大白鲨 and unlocks it at player level 7. Actor scale and collision rules remain level-based.

## Rounded downloaded fish

The 12 Quaternius species now reference derived meshes under `Assets/Art/SmoothFish/`. The original FBX files are retained. One topology-aware subdivision pass rounds body silhouettes; normals are smoothed across UV/material splits without averaging opposite faces of thin fins. Open/non-manifold boundaries stay fixed. UVs, material slots, bindposes and interpolated bone weights are preserved. This adds roughly 2.5–2.8 times the source vertices; it does not run subdivision during gameplay.

Regenerate with **Prepare Rounded Fish And Thumbnails**, or `Chinsekid.FishGame.Editor.FishSkinThumbnailSetup.PrepareRoundedFishAndRender`. The normal iOS export also regenerates the rounded prefabs. Native thumbnails and the fallback shark sprite are rendered from the corresponding real models.
